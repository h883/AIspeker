はじめまして

学校生活を手伝うAIアシスタントです。
最初に、会話に使う Gemini のAPIキーを登録します。

  1. Google AI Studio を開く
  2. 「Create API key」でキーを作る
  3. コピーして下の欄に貼り付ける

接続テストをすると、そのキーで使えるモデルだけに絞り込まれます。

キーは Raspberry Pi の .env にだけ保存され、この画面から中身を読み出すことはできません。 GitHub にも上がりません（仕様書 21章）。

あなたのこと

「明日何時に家を出たらいい？」に答えるために使います。
あとから設定画面で変えられます。

  3. ダウンロードした JSON を下で選ぶ

ウェイクワード

常時待受にはHTTPS接続とマイクの許可、そして画面を開いたままにしておくことが必要です。
呼びかけの判定はこの端末のブラウザ内で行い、Raspberry PiやGeminiへは呼びかけを検知するまで何も送りません。 ただしブラウザの音声認識自体はGoogleの音声サービスを使うため、待受中の音声はGoogleへ送られます。 これを避けたい場合は、Raspberry PiにUSBマイクを付けてopenWakeWordを動かす構成が必要です（README参照）。
